# KEIBA AI PRO - 競馬予想・収支管理 Webアプリケーション
## 完全無料ウェブ公開＆iPhone 17 アプリ化ガイド

PCのWi-Fi設定やファイアウォールに一切左右されず、**世界中どこからでもiPhone 17でアクセスできる「完全無料のWeb公開（HTTPS対応）」** の手順です。

---

## 🚀 最も簡単！完全無料ウェブ公開（3秒で完了）

Web公開用の全ファイルをまとめた **`keiba-app.zip`** を準備済みです。

### 手順（ドラッグ＆ドロップするだけ）

1. フォルダ内の **`【無料ウェブ公開】Netlifyで公開する.bat`** をダブルクリックします。
   - ブラウザで **[Netlify Drop](https://app.netlify.com/drop)** が開きます。
   - 同時に、エクスプローラーで **`keiba-app.zip`** がハイライトされた状態で開きます。
2. ブラウザ画面の破線枠の中に、**`keiba-app.zip` をドラッグ＆ドロップ** します。
3. わずか3秒で、世界中からアクセスできる **専用の無料HTTPS URL（例: `https://xxxx.netlify.app`）** が発行されます！

> [!TIP]
> **アカウント登録なしで即時公開したい場合:**
> ブラウザで **[Tiiny.host](https://tiiny.host/)** を開き、`keiba-app.zip` をアップロードするだけでも即座に `https://xxxx.tiiny.site` が発行されます。

---

## 📲 iPhone 17 でアプリ化（全画面起動）

1. 発行されたURLを **iPhone 17 の Safari** で開きます。
2. 画面下部中央の **「共有（⎋）」** アイコンをタップします。
3. メニューから **「＋ ホーム画面に追加」** を選択し、右上の **「追加」** をタップします。
4. ホーム画面に専用のゴールド＆グリーンのアイコンが追加され、次回から**PCを起動していなくてもワンタップで全画面アプリとして起動**できます！
